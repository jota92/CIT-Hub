CIT HUB EXTENSIONS

拡張機能の開発

TypeScriptで画面と動作を作成し、自分のCIT Hubアプリで検証してから公開審査へ提出できます。

開発用SDKをダウンロード v0.40.0APIリファレンスMarkdown仕様書

1. 開発環境を準備

SDK ZIPを展開し、Node.js 22以降が利用できる環境で開きます。SDKにはTypeScript型定義、ビルダー、使用例が含まれます。

自分で書いたコードのみビルドしてください。ビルド処理は開発PC上でソースを実行するため、出所が分からない拡張機能コードを実行しないでください。

2. TypeScriptをビルド

同梱サンプルを編集してから、コマンドでJSONを生成します。

npm install
npm run build -- examples/study-status.ts

生成された dist/*.json を開発者コンソールのアップロード欄で選択します。SDKは利用するAPIに合わせて最低ホストバージョンを記録します。古いアプリでは互換性がない版を起動できません。

3. 自分のアプリでテスト

  1. CIT Hubの拡張機能タブから設定を開き、開発者アカウントを作成します。
  2. 開発者コンソールへログインし、ビルドしたJSONをアップロードします。
  3. 同じCIT Hubアカウントでアプリの拡張機能タブを開き、本人用プレビューを実行します。

開発版の保存データは公開版と分離されます。APIが使えない場合は、ホストバージョン・宣言権限・端末設定を確認してください。

4. 公開を申請

開発者コンソールから機能説明を添えて審査へ提出します。更新時は変更内容を記載します。承認されるまでは一般の利用者へ配布されません。拡張機能名は原則として作成後に変更できません。

審査では、必要な権限、扱うデータ、外部通信先、利用者が行う操作、エラー時の挙動を確認します。個人情報や秘密情報を収集する機能は追加できません。

権限と安全性

  • 利用するCIT Hubデータ・端末機能だけをmanifestへ宣言します。
  • 権限宣言とOS権限は別です。カメラ・位置情報・通知などは必要時に利用者の操作を経て要求します。
  • 拡張機能のTypeScriptはQuickJS隔離環境で動き、DOM・任意ネイティブコード・無制限のファイルアクセスは利用できません。
  • Portal/Manabaのパスワード、OTP秘密鍵、Cookie、CIT Hubセッショントークン、他ユーザー情報はAPIで公開しません。
  • ユーザー間共有、サーバーFunctions、WebSocket、OSウィジェットなど未実装のAPIは利用できません。

実装済みAPI、型、permission、容量・実行制限はAPIリファレンスと詳細仕様書を参照してください。
