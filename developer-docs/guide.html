CIT HUB EXTENSIONS

拡張機能の開発

HTML Web App方式で画面と動作を作成し、自分のCIT Hubアプリで検証してから公開審査へ提出できます。

開発用SDKをダウンロード v0.51.0APIリファレンスMarkdown仕様書

接続APIの注意
WebSocketはHost API v48で利用できます。WSS・標準ポート443・manifestに宣言したホストに限定され、画面を離れると切断されます。使用条件はAPIリファレンスをご確認ください。

1. 開発環境を準備

SDK ZIPを展開し、Node.js 22以降が利用できる環境で開きます。SDKにはWeb Appビルダー、APIリファレンス、HTMLサンプルが含まれます。

自分で書いたコードのみビルドしてください。ビルド処理は開発PC上でソースを実行するため、出所が分からない拡張機能コードを実行しないでください。

2. ビルドしてJSONを作る

HTML・CSS・JavaScriptで画面、ゲーム、ルーレット、Canvasアニメーションを作り、Web Appとしてビルドします。外部ファイルは使わず、CSSとJavaScriptをHTMLへインラインで記載します。

npm install
npm run build:web -- examples/web-app-study-timer.html \
  --metadata examples/web-app-study-timer.json \
  --out dist/study-timer.json

metadata JSONには name、version、description、permissionsを記載します。ビルダーは schemaVersion: 2、ui.mode: "web"、content: []を付け、HTMLを manifest.webApp.files["index.html"]へ埋め込んだアップロード用JSONを生成します。生成された dist/*.jsonを開発者コンソールへアップロードしてください。HTMLは300KB以内です。

Web AppからCIT Hubのデータや機能を使う場合は、HTML内のJavaScriptから window.CITHub.call(operation, args)を呼びます。外部通信、fetch、XMLHttpRequest、iframe、外部リソース、eval、Function、動的importは使えません。詳しいoperationと権限はWeb App APIを確認してください。

3. 自分のアプリでテスト

  1. CIT Hubの拡張機能タブから設定を開き、開発者アカウントを作成します。
  2. 開発者コンソールへログインし、ビルドしたJSONをアップロードします。
  3. 同じCIT Hubアカウントでアプリの拡張機能タブを開き、本人用プレビューを実行します。

開発版の保存データは公開版と分離されます。APIが使えない場合は、ホストバージョン・宣言権限・端末設定を確認してください。

4. 公開を申請

開発者コンソールから機能説明を添えて審査へ提出します。更新時は変更内容を記載します。承認されるまでは一般の利用者へ配布されません。拡張機能名は原則として作成後に変更できません。

審査では、必要な権限、扱うデータ、外部通信先、利用者が行う操作、エラー時の挙動を確認します。個人情報や秘密情報を収集する機能は追加できません。

権限と安全性

  • 利用するCIT Hubデータ・端末機能だけをmanifestへ宣言します。
  • 権限宣言とOS権限は別です。カメラ・位置情報・通知などは必要時に利用者の操作を経て要求します。
  • Web AppはローカルWebViewで隔離され、外部スクリプト、任意の外部通信、動的コード実行、任意のネイティブコードは利用できません。
  • Portal/Manabaのパスワード、OTP秘密鍵、Cookie、CIT Hubセッショントークン、他ユーザー情報はAPIで公開しません。

実装済みAPI、権限、容量・実行制限はAPIリファレンスと詳細仕様書を参照してください。
