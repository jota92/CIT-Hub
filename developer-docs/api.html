はじめに

SDK ZIPを展開し、HTMLファイルとmetadata JSONを作成します。

npm install
npm run build:web -- examples/web-app-study-timer.html \
  --metadata examples/web-app-study-timer.json \
  --out dist/study-timer.json

生成物はschemaVersion: 2、ui.mode: "web"、content: []、webApp.files["index.html"]を含みます。

manifest

{
  "schemaVersion": 2,
  "ui": { "mode": "web" },
  "content": [],
  "webApp": {
    "entry": "index.html",
    "entrypoint": "index.html",
    "files": { "index.html": "<!doctype html>..." },
    "contentHash": "sha256-..."
  }
}

HTMLファイルをエントリーポイントとして指定します。

Web App

Web AppはCIT Hub内の隔離されたローカルWebViewで実行されます。外部スクリプト、外部CSS、外部画像、iframe、fetch、XHR、WebSocket、Service Worker、eval、Function、動的import、任意のネイティブコードは使用できません。

画面は標準DOM、CSS、SVG、Canvas、Web Animationsで作成できます。

CIT Hubブリッジ

HTMLからCIT Hubの機能を使う唯一の入口はwindow.CITHubです。

const host = await window.CITHub.ready();
const today = await window.CITHub.call('cit.timetable.today', {});
const stop = window.CITHub.on('resume', () => refresh());

ready()はホスト情報、on()は解除関数、call()は権限と端末Capabilityを検査した結果を返します。非同期処理は必ずtry/catchで扱います。

保存

storage.get/set/has/remove/keysは拡張機能・ユーザーごとの端末内保存です。secureStorageは保護領域、files.*は拡張機能専用領域です。他ユーザーのデータは取得できません。

拡張機能サーバー

server.function、server.cron.*、server.files.*、server.db.*、server.kv.*は宣言権限と審査を必要とします。パスワード、OTP、Cookie、セッショントークン、管理者データ、他ユーザーのデータは渡されません。

権限と安全性

利用する本人データ・端末機能だけをpermissionsへ宣言します。権限、OS許可、ユーザー操作、Host APIバージョンをホストが検査します。外部通信が必要な場合もHTMLから直接通信せず、許可されたブリッジを使用します。

エラー

permission_denied、user_action_required、unsupported、network_error、not_found、rate_limited、storage_error、validation_error、host_update_requiredを画面へ表示し、再試行や設定変更を案内してください。
