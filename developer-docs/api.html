APIの全体像

拡張機能はアプリ内の隔離されたTypeScriptランタイムで動作します。画面はiOS・AndroidのネイティブUIで描画し、CIT Hubの個人データは端末内で読み取ります。

最初のAPI呼び出し

import { app, capabilities, cit } from '../sdk/index';

const host = app.hostVersion();
const canReadSchedule = capabilities.has('timetable.read');
const nextClass = canReadSchedule ? await cit.timetable.next() : null;

console.log({ host, nextClass });

APIは機能単位の権限とホストCapabilityを検査します。権限が宣言されていない場合や、古いアプリに必要なAPIがない場合は、呼び出しは明示的なエラーになります。

対応状況の見方

APIの利用可否はOSや端末の機能により異なります。必要に応じて実行時Capabilityとエラーを扱ってください。

●実装済みAPI

本ページで説明する範囲。個別のOS制約・権限・データ取得条件は各節に記載しています。

●制約・部分対応あり

OSや元データの制約を受けます。例: 端末内キャッシュがない場合のデータAPI、OSに任される通知時刻。

●未提供

APIとして公開していない機能です。計画・要望・SDK上の型だけでは利用可能とは限りません。

セキュリティ境界
拡張機能はPortal/Manabaのパスワード、OTP秘密鍵、Cookie、他ユーザー情報、任意ネイティブコードにアクセスできません。本人データも宣言権限の範囲に限られ、外部送信は開発者が記述した処理に対して接続先を限定します。

はじめに

SDK ZIPを展開し、Node.js 22以降の環境で開発キット内のビルダーを使います。サンプルのソースを編集し、生成したJSONを開発者コンソールへアップロードしてください。

npm install
npm run build -- examples/study-status.ts

TypeScriptソースは開発者のPC上でビルドされます。信頼できないソースをビルドしないでください。アップロードされたコードをCIT Hubのサーバーで実行することはありません。

実行型拡張機能

import { defineProgram, interactive, state, ui } from '../sdk/index';

const count = state.create(0);
export default defineProgram({
  name: 'カウンター',
  version: '1.0.0',
  description: '操作回数を数えます',
  permissions: [],
  render: () => [
    ui.page('カウンター', [
      ui.heading(`現在 ${count.value}`),
      interactive.button('1増やす', () => count.set(count.value + 1))
    ])
  ]
});

defineProgram は隔離ランタイムで処理し、画面はネイティブ部品で描画します。DOM、任意のネイティブコード、グローバルなfetch、Portal/ManabaのCookieや秘密情報にはアクセスできません。

状態同期する選択入力（host API v32）

const campus = state.create('新習志野');
interactive.select('campus', 'キャンパス', ['新習志野', '津田沼'], campus);
ui.text(`選択中: ${campus.value}`);

選択肢を選ぶと値がStateに入り、そのStateを参照する画面が更新されます。選択肢は1〜100件、1件200文字以内で重複不可です。SDKはこの入力を使う拡張機能に minimumHostAPI: 32 を設定します。

状態同期する複数選択（host API v34）

const supplies = state.create<string[]>(['講義資料']);
interactive.multiSelect('supplies', '持ち物', ['講義資料', '実験器具'], supplies);
ui.text(`選択中: ${supplies.value.join('、')}`);

複数選択UIはiOS・iPadOS・macOSとAndroidのネイティブ部品で表示されます。更新値は文字列配列としてStateへ同期されます。選択肢は1〜30件、各120文字以内で重複不可です。SDKが minimumHostAPI: 34 を設定します。

状態同期する日時入力（host API v35）

const reminderAt = state.create<number | null>(null);
interactive.dateTime('reminderAt', '通知する日時', reminderAt);
ui.text(reminderAt.value === null ? '未設定' : `${reminderAt.value} ms`);

OS標準の日付・時刻選択UIを使い、選択値はUnix epochミリ秒でStateに同期します。未設定は null です。SDKは minimumHostAPI: 35 を設定し、対応前のアプリでは起動できません。

状態同期する日時範囲（host API v36）

const period = state.create<{start:number|null;end:number|null}>({start:null,end:null});
interactive.dateRange('period', '対象期間', period);

開始・終了を別々に設定でき、各値はUnix epochミリ秒または null です。終了より後の開始日時は拒否し、ネイティブUIでは逆転しないよう補正します。SDKは minimumHostAPI: 36 を付けます。実例: extensions/examples/interactive-date-range.ts

複数行テキスト入力（host API v23）

const memo = state.create('');
interactive.textArea('memo', '授業メモ', memo);
ui.caption(`${memo.value.length} / 4000`);

入力値はStateへ反映され、入力上限は4,000文字です。端末内へ保存する場合は、用途に合うstorageなどのAPIと権限を別途使用してください。

保存・データベース

端末内Key-Value

storage.get/set/has/remove/clear/keys は本人・拡張機能・開発/公開環境ごとに分離されます。拡張機能固有データを最大256KB保存できます。他端末との同期はしません。

保護された端末内保存

secureStorage.get/set/delete はiOS/macOSのKeychainまたはAndroidの暗号化保存を使います。CIT Hub本体の認証情報にはアクセスできません。

ローカルデータベース

database.createTable/insert/update/delete/get/query/transaction/watch。比較条件、並べ替え、件数制限のクエリをSDKで構成できます。スキーマは拡張機能専用でSQLite互換ではなく、非同期処理をtransaction callbackから実行できません。

ユーザー専用Cloud KV

cloudUser.get/set/delete はCIT Hubアカウントと拡張機能に隔離されます。revisionによる競合検出、暗号化、容量上限があります。サーバーFunctionsやユーザー間共有ではありません。

ファイル

拡張機能専用領域（host API v30）

await files.write('draft.txt', new TextEncoder().encode('メモ'));
const bytes = await files.read('draft.txt');
await files.copy('draft.txt', 'backup.txt');
await files.move('backup.txt', 'archive.txt');
const names = await files.list();

権限はfiles.storage。最大256KiB/ファイル、最大100ファイル・合計5MiBです。ファイル名のみを受け付け、パス区切り、親ディレクトリ指定、シンボリックリンク、既存宛先への上書きを拒否します。拡張機能の領域外へアクセスできません。

ユーザーが選ぶファイル

静的UIのui.fileに加え、実行型TypeScriptではボタン操作からfiles.pick()、files.pickImage()、files.pickVideo()、files.pickAudio()、files.pickDocument()を呼び出せます。OS標準ピッカーで1ファイルを選び、キャンセル時はnullを返します。Host API v50ではfiles.pickMultiple(kind?)で最大10ファイルを一度に選べます。複数選択の戻り値はファイル情報の配列、キャンセルはnullです。いずれもfiles.userとfiles.selection.readが必要で、各ファイル10MiB・複数選択の合計20MiBまで端末内の拡張機能専用領域へ保存します。files.readSelected(key, offset, maxBytes)で最大48KiBずつ読み取れます。Host API v52のfiles.export(name, suggestedName?)と同義のfiles.saveAs(name, suggestedName?)は、専用領域のファイルをOS標準の保存画面へ渡し、利用者が保存先を決めます。files.storageが必要で、利用者操作なしの書き出し・任意パスアクセスには対応しません。

写真・メディア・共有

ui.coursePicker、ui.capturePhoto、ui.importPhotos、ui.photoGrid で、授業選択・撮影・写真取り込み・一覧を組み合わせられます。データは端末内の拡張機能専用領域に保存します。ユーザー操作なしの撮影や写真ライブラリ全体の列挙はできません。

ui.image/video/audio は許可されたHTTPSメディアを表示します。ui.file でユーザーが選んだファイルをアプリ内プレビューまたは対応アプリへ渡せます。ui.shareText、ui.copyText は利用者の操作から実行します。

OS標準の共有シート（Host API v52）

実行型TypeScriptからshare.text(text)、share.url(url)、share.items(items)を呼ぶと、利用者が押したボタンに応じてOS標準の共有先選択を表示します。対応する内容はテキストとHTTPS URLです。1回につき1〜10項目、テキストは1項目8KiB以下、合計16KiB以下です。直接の利用者操作が必須で追加権限はありません。キャンセルや共有先アプリの完了状態はOS標準UIに委ねられ、送信完了をアプリへ保証しません。

選択済みファイルの共有（Host API v53）

share.file(key)は利用者がfiles.pick()等で選択したファイルをOS共有画面に渡します。files.userとfiles.selection.read権限、直接操作が必要です。任意パスは扱わず、1件10MiB・合計20MiBに制限します。ファイルはCIT Hubサーバーへ送られません。

選択済み画像の縮小・JPEG変換（Host API v54）

files.transformImage(key, outputName, options?)は利用者が選択した画像を端末内で縮小し、JPEGとして拡張機能専用領域に保存します。files.selection.readとfiles.storage、直接操作が必要です。入力10MiB以下、最大辺256〜2048px、品質0.35〜0.9、出力240KiB以下。EXIF方向を補正し、元画像は変更せず、通信も行いません。

全コーデック、画像編集、録音、PDFページ操作のすべてをサポートするわけではありません。対応OS・形式はAPI仕様を確認してください。

ネットワーク

network.status() と network.onChange(callback) は端末の接続状態を参照します。接続先名、IP、SSIDは返しません。

const response = await network.fetch('https://api.example.com/items', {
  method: 'GET',
  headers: { Accept: 'application/json' }
});
if (!response.ok) throw new Error(`HTTP ${response.status}`);

network.fetch/get/post/put/patch/delete は network.fetch 権限とmanifestの許可ホスト宣言を必要とします。HTTPS標準ポートのみ、Cookie/Host等の危険なヘッダーは禁止、本文32 KiB・応答256 KiB・ヘッダー20個までです。リダイレクトは追従せず、プライベート・予約済みIPに解決される接続先も拒否します。Androidは検査したDNS応答を接続時にも固定します。iOS/iPadOS/macOSは接続前にDNSを検査しますが、接続時の名前解決はURLSessionが行うため、同じDNS固定の保証はありません。両実装でシステムプロキシは利用しません。任意ホストを宣言なく呼び出すことはできません。

ファイル転送（host API v33）

const downloaded = await network.downloadFile(
  'https://api.example.com/handout.pdf',
  'handout.pdf'
);
if (downloaded.ok) {
  const bytes = await files.read(downloaded.file.name);
  // bytes は拡張機能専用ストレージから読み出した Uint8Array
}

network.downloadFile(url, destinationName, headers?) は取得したファイルを拡張機能専用ストレージへ保存し、名前・サイズ・HTTP状態を返します。network.uploadFile(url, sourceName, options?) は同じ専用領域に保存済みのファイルをPOSTまたはPUTで送ります。どちらも利用者が押したボタンの処理中に呼ぶ必要があり、network.fetch と files.storage の両権限、manifestの完全一致HTTPSホスト宣言が必要です。任意の端末ファイルパスにはアクセスできません。

ファイル転送はリクエスト・レスポンス各256 KiBまでです。ダウンロードはリダイレクトしません。保存時は拡張機能専用ストレージのファイル名・件数・総容量制限を適用します。通常のテキスト通信も応答上限は256 KiBです。通信先には端末のIP等が伝わり、アップロードしたファイルの内容も通信先へ渡ります。

ファイル転送の進捗（Host API v55）

await network.downloadFile(url, 'handout.pdf', {
  headers: { Accept: 'application/pdf' },
  onProgress: ({ loadedBytes, totalBytes, fraction }) => {
    status.set(totalBytes == null ? `${loadedBytes} bytes` : `${Math.round((fraction ?? 0) * 100)}%`);
  }
});

onProgressは転送中に約100ms間隔で通知され、完了時にも呼び出されます。サーバーがContent-Lengthを返さない場合、totalBytesとfractionはnullです。登録したコールバックは該当転送の完了・失敗時に解除されます。実行環境ではnetwork.transferProgressをcapabilityとして確認できます。

セキュアWebSocket（Host API v48）

network.websocket.connect(url)はnetwork.fetch権限とmanifestの許可ホストを使い、標準ポート443のwss://に接続します。Cookie・Webセッションは共有しません。Androidは検査済みDNS応答を接続にも固定し、iOS/iPadOS/macOSは接続前検査のみで接続時のDNS固定は行いません。1拡張機能につき接続は1つ、テキストは送受信各4 KiB、各30フレーム/分です。バイナリ、任意ポート、リダイレクト、バックグラウンド接続は未対応で、画面を離れると切断します。接続先には端末のIPアドレス等が伝わります。

const socket = await network.websocket.connect('wss://stream.example.net/events');
socket.onMessage(text => status.set(text));
socket.onClose(event => status.set(`切断: ${event.code}`));
socket.onError(code => status.set(code));
await socket.ready;
await socket.send('subscribe');
await socket.close();

利用者の画面操作から接続してください。実例: extensions/examples/runtime-websocket.ts。ビルダーはminimumHostAPI: 48を設定します。

端末・位置情報・触覚

device.info/platform/osVersion/deviceClass/screen/locale/timezone/appearance/capabilities は画面やOSの情報を返します。端末固有識別子は提供しません。

読み込み・空・エラー状態

ui.loading(label)、ui.emptyState(title, message)、ui.errorState(title, message)は、読み込み中・該当データなし・エラーを区別して伝える標準UIです。iOS・iPadOS・macOS・Androidでネイティブ描画します。SDKビルダーは最低Host API v39を自動設定し、古いホストでは互換性エラーとして起動を防ぎます。

ui.loading("時間割を読み込み中")
ui.emptyState("課題はありません", "新しい課題が届くとここに表示されます")
ui.errorState("読み込めませんでした", "通信状態を確認して再度お試しください")

カード・グループ・コンテナ

ui.card(children, label?) はOS標準のカード面、ui.group(children) は背景を足さず間隔を整理するグループ、ui.container(children) は画面幅に追従する領域です。固定座標に依存せず、iOS・iPadOS・macOS・AndroidのネイティブUIで表示します。最低Host API v40が必要で、SDKが最低バージョンを自動記録します。

ui.container([
  ui.card([ui.heading("今週の授業"), ui.data("timetable.week")], "時間割"),
  ui.group([ui.caption("操作"), ui.button("更新", "refresh")])
])

ネイティブアニメーション

animation.animate(options, update) は更新関数内のState変更をネイティブ画面へ渡し、iOS・iPadOS・macOSではSwiftUI、AndroidではComposeのレイアウトアニメーションとして描画します。期間は0.05〜1.5秒、曲線はlinear/easeIn/easeOut/easeInOut/springに限定します。自由な描画ループは実行しません。

await animation.animate({ duration: 0.25, curve: "easeInOut" }, () => {
  expanded.set(!expanded.value);
});
await animation.spring(() => expanded.set(true), { damping: 0.82 });

利用にはHost API v41が必要です。SDKビルダーが最低ホストバージョンを設定し、未対応端末では起動を拒否します。

状態と同期する入力コントロール

interactive.stepper、interactive.checkbox、interactive.radioはOS標準の入力UIを使用し、ユーザーの変更を型付きイベントとしてTypeScript Stateへ反映します。範囲・刻み・選択肢はビルド時とサーバーで検証されます。Host API v37。

interactive.stepper("count", "個数", count, 0, 10, 1)
interactive.checkbox("ready", "確認しました", ready)
interactive.radio("campus", "キャンパス", ["新習志野", "津田沼"], campus)

進捗表示

ui.progress(label, value)はOSネイティブの線形進捗表示です。値は0から1までの有限値で指定し、SDKビルドが最低Host API v38を設定します。

ui.progress("ファイルを処理中", 0.62)

横棒グラフ

ui.barChart(title, categories, series)はカテゴリ1〜12件、系列1〜4件、0〜1,000,000の有限値からOS標準の横棒表示を作ります。各系列の値数はカテゴリ数と一致させます。自由なCanvas描画は行いません。Host API v42が必要です。

ui.barChart("今週の学習時間", ["月", "火", "水"], [{ label: "時間", values: [1.5, 2, 0.75] }])

Safe Area とレスポンシブ寸法

ui.safeArea(children)はノッチ・システムバー・画面端を避けるOSネイティブ領域です。ui.frame(node, bounds)では最小/最大の幅と高さ、縦横比を指定できます。単位はiOS/macOSがpt、Androidがdp。幅・高さは0〜2000、縦横比は0.1〜10で、最小値は最大値以下である必要があります。最低Host API v43です。

ui.safeArea([ui.frame(ui.column([ui.heading("今週の授業"), ui.data("timetable.periods")]), { minWidth: 240, maxWidth: 860 })])

入力フォーカスと送信イベント

interactive.textFieldとinteractive.secureFieldはonFocus、onBlur、onSubmitを受け取ります。複数行textAreaではonSubmitを提供しません。入力値とフォーカス状態は端末内QuickJSで扱い、サーバーに送信しません。Host API v44が必要です。

interactive.textField("query", "キーワード", query, {
  onFocus: () => status.set("入力中"),
  onBlur: () => status.set("入力終了"),
  onSubmit: () => status.set(query.value),
})

ネイティブアイコンボタン（Host API v45）

interactive.iconButton(icon, label, onPress)はOS標準アイコンを44pt/dp以上のタップ領域で表示し、VoiceOverとTalkBack用ラベルを設定します。許可アイコンはbook、calendar、bus、check、clock、info、map、person、photo、plus、search、edit、list、bellです。

interactive.iconButton("plus", "回数を増やす", () => count.set(count.value + 1))

ネイティブ検索欄（Host API v46）

interactive.searchField(key, label, value, events?)はStateと同期する検索用ネイティブ部品です。検索アイコン、入力消去、検索キーを備え、最大4,000文字です。Host API v46以降が必要です。

const query = state.create('');
interactive.searchField('query', '課題名を入力', query, {
  onSubmit: () => searchAssignments(query.value)
});

実例: extensions/examples/interactive-search-field.ts

ネイティブリンクボタン（Host API v47）

ui.linkButton(label, httpsURL)はOS標準のリンク動作を使う強調ボタンです。VoiceOver・TalkBackにリンクとして認識され、44pt/dp以上の操作領域で表示します。HTTPSのみ、ユーザー情報を含まないURLに限定します。静的UI・実行型UIの両方で使え、ビルダーがminimumHostAPI: 47を設定します。

import { defineExtension, ui } from '../sdk/index';

export default defineExtension({
  name: '参考リンク', version: '1.0.0',
  description: '公式情報を開く', permissions: [],
  content: [ui.linkButton('大学公式サイトを開く', 'https://www.it-chiba.ac.jp/')]
});

HTTP、資格情報付きURL、2,000文字を超えるURLはビルド時・サーバー側・アプリ側で拒否します。Host API v46以前のアプリでは起動できません。

外部ブラウザを開く（Host API v56）

browser.openExternal(url)は、端末の既定ブラウザでHTTPSリンクを開きます。browser.open権限と、利用者が押したボタンからの呼び出しが必要です。標準ポート443のみ、URLは2048文字までで、ユーザー名・パスワードを含むURLは拒否します。ブラウザのDOM、Cookie、ログイン状態は取得しません。SDKビルダーがminimumHostAPI: 56を設定します。

import { browser, interactive } from '../sdk/index';
interactive.button('大学公式サイト', async () => {
  await browser.openExternal('https://www.it-chiba.ac.jp/');
});

書類スキャン（Host API v64）

scanner.document({ name, maxPages })は、利用者の明示操作でOSの書類スキャナーを開き、PDFを拡張機能専用領域に保存します。image.scanDocument()は同じ処理の別名です。camera.useとfiles.storageの両方が必要です。

const scanned = await scanner.document({ name: 'notes.pdf', maxPages: 8 });
if (scanned) {
  // PDF is available in this extension's private storage.
  console.log(scanned.pageCount, scanned.size);
}

キャンセル時はnull、PDFが5 MiBを超えた場合はエラーです。保存ファイルは既存の拡張機能ストレージ5 MiB枠と100ファイル枠を共有します。iOSはVisionKit、AndroidはGoogle ML Kitを利用します。Mac Catalystでは利用できません。撮影内容は自動送信されません。

バックグラウンド状態（Host API v68）

background.status()はOSの現在のバックグラウンド更新設定を読み取ります。iOS/iPadOSではBackground App Refresh、Androidではバックグラウンド制限状態を返し、Android API 28未満や判定不能時はunknownです。Mac Catalystはunsupportedです。availableでも実行時刻や実行回数は保証されません。このAPIにタスク登録・解除機能はありません。

import { background } from './sdk';
const status = await background.status();
console.log(status.availability, status.mayRun);

サーバー定期実行結果（Host API v72）

server.cron.register(name,input,intervalSeconds)は承認済み・インストール済み拡張機能のサーバー関数を拡張機能サーバー上で実行します。server.functionsが必要です。間隔は15分〜30日、1拡張5ジョブまで。連続3回失敗すると自動停止します。最新成功結果はアカウント別に暗号化保存され、statusで状態・次回実行・最終実行・結果・安全なエラーコードを確認できます。入力16KiB・実行100ms・結果32KiBです。サーバー停止中の実行や正確な時刻は保証されません。

await server.cron.register("dailySummary", { mode: "compact" }, 86400); await server.cron.status("dailySummary"); await server.cron.unregister("dailySummary");

Realtimeグループ通信（Host API v70）

realtime.publish(groupID, topic, value)で参加済み招待制グループへJSONイベントを送信し、realtime.subscribe(...)で取得します。サーバー採番で順序を維持し、各topicの最新イベントを保持します。これは常時接続ではなくHTTPSポーリングで、既定2.5秒・設定範囲1〜30秒です。バックグラウンドpushや履歴配送はしません。cloud.shared権限、グループ参加、topic最大64文字、payload最大12KiBが必要です。

import { realtime } from './sdk';
const stop = realtime.subscribe(groupID, 'status', event => console.log(event.sequence, event.value));
await realtime.publish(groupID, 'status', { open: true });
stop();

ネイティブ地図（Host API v67）

map.view()にマーカー、線、円、範囲フィットを渡せます。現在地は自動取得しません。iOS/iPadOS/macOSはMapKit、AndroidはOpenStreetMapタイルを使います。Androidのタイルには常時帰属表示があり、表示中の範囲だけを標準キャッシュ規則で読み込みます。オフライン地図・一括取得は提供しません。OSMタイル利用規約に従います。

map.view({center:{latitude:35.68,longitude:139.76},zoom:14},[map.marker({latitude:35.68,longitude:139.76},{title:"駅"})])

テキストのドラッグ＆ドロップ（Host API v66）

拡張機能の同じ画面内で、拡張機能が明示したテキストをOS標準のドラッグ操作で受け渡します。追加権限は不要です。ファイル、他拡張機能の値、端末内データのドラッグには対応しません。文字列は4,000文字以内です。

import { defineProgram, drag, ui } from './sdk';
export default defineProgram({
  name: '文字を移動', version: '1.0.0', description: '画面内で文字を渡します',
  permissions: [],
  render: () => [
    drag.source('ドラッグする文字', '共有するテキスト'),
    drop.target('receivedText', 'ここにドロップ'),
    ui.text('受け取った内容: {{receivedText}}')
  ]
});

drop.target(key,label)で受け取った値は、その拡張機能内の画面状態にだけ反映されます。ホストAPI v66が必要です。

ボタンの長押し・ダブルタップ

通常のタップに加えて、ネイティブボタンで長押しとダブルタップを別々のコールバックとして処理できます。利用時はHost API v79が必要です。SDKビルド時に最低バージョンを自動設定します。

interactive.button('授業', openCourse, {
  onLongPress: () => showActions(),
  onDoublePress: () => toggleFavorite()
});

イベントは画面上のユーザー操作時にだけ実行されます。権限や実行中状態によってボタンが無効な間は呼び出されません。
